# my_tools.txt - when Iris should answer with a tool tag. YOURS TO EDIT.
#
# Same format as my_chats.txt (several User lines = ways of asking, then
# one Iris line). Here Iris's answer is a TAG that the Iris app runs with
# real data from the kernel (docs/LLM.md, "Tools"):
#
#   [disk]            used / free / total disk space, number of files
#   [memory]          RAM and heap in use
#   [time]            date, time and uptime
#   [files]           the files with their sizes
#   [find "x"]        files whose name or text contains x
#   [open "NAME"]     open a file in Notepad
#   [make-app TEMPLATE slot=value ...]   build a small app from a template:
#       message  title="..." text="..."
#       box      title="..." color=C size=small|medium|large
#       counter  title="..." color=C
#       clock    title="..." color=C
#       button   title="..." text="..." color=C
#
# {word}, {file}, {title}, {text}, {color} and {size} are filled in with
# random values from the "@" lists below, a new pick for every example,
# so Iris learns to copy whatever you type into the tag. The same
# placeholder gets the same value in the User and Iris lines.
#
# The values in each list are separated by " | ". Every block below is
# repeated many times with different fills (prepare_data.py, TOOL_REPEATS).

@word: notes | hello | todo | planck | test | letter | recipe | secret | ideas | music | dog | cat | budget | plan | story | code | main | game | list | draft | report | poem | readme | shopping | homework | birthday | iris | kernel | window | apple | summer | meeting
@file: NOTES.TXT | HELLO.ASM | TODO.TXT | LOOP.ASM | README.TXT | PLAN.TXT | IDEAS.TXT | DIARY.TXT | CLICK.ASM | LIST.TXT | POEM.TXT | GAME.ASM | DRAFT.TXT | LETTER.TXT | MAIN.ASM | SONG.TXT | notes.txt | todo.txt | hello.asm
@title: Clicks | Taps | Hello | Counter | Boxy | Timer | Greeter | Ping | Buddy | Sunny | Pixel | Score | Welcome | Tick | Note | Bloop | Zap | Party | Demo | Hi | Lamp | Moon | Star | Dash
@text: Hello there! | Have a nice day | Welcome to planckOS | You can do it | Press me | Click here | Good morning | Hi friend | Go team | Coffee time | I love planckOS | Stay curious
@color: red | green | blue | yellow | orange | purple | white | black | pink | gray | cyan
@size: small | medium | large
