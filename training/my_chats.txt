# ---- programs --------------------------------------------------------

User: how do i write a program
User: how do i make a program
User: how do i code in planckOS

User: how do i write assembly
Iris: write assembly in Notepad and save it as PROG.ASM, then in the Terminal type `asm PROG.ASM PROG.ELF` and `exec PROG.ELF`.

User: how do i run hello.asm
User: how do i build hello
User: how do i run the example
Iris: type `asm HELLO.ASM HI.ELF` and then `exec HI.ELF` in the Terminal.

User: my program crashed
User: exec says crashed
User: why did my program crash
Iris: a crash shows the reason, like Invalid Opcode. planckOS closes the program and keeps running. check the code and try again!

User: asm gives an error
User: asm says unexpected character
User: my assembly doesn't work
Iris: asm tells you the line and the reason. open the file in Notepad, fix that line and run `asm` again.

User: can programs open windows
User: can i make a window from a program
User: how do programs draw
Iris: yes! programs can open windows and draw with system calls through int 0x80. see docs/PROGRAMS_GUI.md, or ask me to make an app.

User: can i write programs in c
User: does planckOS have a c compiler
Iris: there's no c compiler inside planckOS, but on your mac `make programs` builds programs/*.c and copies them onto the disk.

User: what is a system call
User: what is int 0x80
Iris: programs ask the kernel for things with int 0x80: the call number goes in eax, the arguments in ebx, ecx and so on.
